# 🏫 مدرستي — نظام إدارة المدارس المتكامل (متعدد المدارس)

تطبيق ويب **بملف واحد** يعمل دون خادم لإدارة المدارس العراقية: الطلاب، الملاك، الدرجات، النتائج والطباعة، الغياب، الممتلكات، القيود، المخاطبات، الجداول المدرسية، ونظام **تعدد المدارس التجاري** (تجربة 5 أيام، اشتراكات، حسابات مديري مدارس، دعم فني، إيرادات) — مع طبقة تكامل جاهزة للربط مع **Supabase**.

> تصميم وتطوير: **الأستاذ حسين ناهي المسعودي** 🇮🇶

---

## ✨ أبرز الميزات
- 📊 إحصائيات ولوحات ومتابعة يومية، بحث وطباعة وتصدير/استيراد Excel/PDF.
- 🎯 سجلات درجات 1–6 مع حساب تلقائي للمعدلات وبطاقات نتائج بطباعة A4/A5 وQR.
- 📈 تطبيق «الجدول المدرسي» مدمج ومعزول لكل مدرسة، يستورد الملاك (اسمان لكل معلم) تلقائياً.
- 🏘️ **لوحة تعدد المدارس**: إضافة/تعديل/حذف/تجديد اشتراك، تقارير (طلاب/معلمين/استهلاك أسبوعي)، إيرادات.
- 🔐 حسابات مديري مدارس تُنشأ تلقائياً (Hash+Salt)، نسخ/طباعة/إرسال بيانات الدخول، إعادة تعيين آمنة.
- 🎁 فترة تجريبية 5 أيام + قسم **دعم فني** يوصل رسائل الزبائن باسم مدارسهم.
- 🛡️ تدقيق هندسي وأمني مُنفَّذ (انظر `docs/audit-report-ar.md`).

## ▶️ التشغيل
1. نزّل `app/madrasaty.html`.
2. افتحه في Chrome/Brave (يعمل محلياً 100%، وبياناتك تُحفظ على الجهاز).
3. الدخول الافتراضي للمطور: المستخدم `admin` (أو المخصص) + رمز القفل الخاص بك.

## ☁️ الربط مع Supabase (اختياري — الخطة المجانية)
1. أنشئ مشروعاً مجانياً من https://supabase.com/dashboard
2. نفّذ `supabase/schema.sql` في **SQL Editor**.
3. من **Settings ← API** انسخ `Project URL` و`anon key`.
4. في التطبيق: **المدارس ← بطاقة ☁️ الربط مع Supabase** ← الصق ← حفظ ← اختبار ← رفع/سحب.
   التفاصيل كاملة في `docs/supabase-guide-ar.md`.

## 🔒 الأمان
- كلمات المرور مُجزّأة (Hash+Salt) ولا تُخزن نصية.
- عزل كامل بين بيانات المدارس + معرّف مزامنة سرّي (tenant).
- توصية إنتاجية: فعّل Supabase Auth واستبدل سياسات RLS المفتوحة (التفاصيل في تقرير التدقيق).
